# Presenter notes - Manager session 5: Monitoring cadence and dashboards

Audience: middle management and team leads. The most operationally useful session - people leave
and change their calendar and their dashboard the same week.

## Before the session
- Screenshot one genuinely bad tile from your own dashboard (a naked number, no target, no trend).
  Fixing your own tile live is worth more than fixing Cartwheel's.
- Have Grove's task-relevant maturity ready with the inversion: a senior person on a new task
  needs more check-in, not less.
- Know your own current cadence and be honest if it is set by the calendar rather than by
  maturity. Admitting that buys you the room.

## Timing (45 min)
- 0-3: Recap, where we are
- 3-20: Part 1 - three horizons, three different questions; the 1:1 is the report's meeting
- 20-27: Part 2 - dashboards done right, no naked numbers
- 27-39: Worked example 1 - set a cadence for a Cartwheel team
- 39-43: Worked example 2 - fix a bad dashboard tile
- 43-45: Q&A

## Worked-example run-of-show
- Worked example 1: the contrast is the teaching device - a mature email programme that runs
  itself versus a brand-new paid-social channel nobody has run before. Same owner, different
  cadence, set by maturity not by ownership.
- Insist they write it into a table. A cadence that lives in a manager's head is a mood, not a
  shared expectation.
- Worked example 2: build the tile up one layer at a time and let the room feel each addition.
  Revenue $1.2M means nothing. Add target (plan was $1.15M, so +4%). Add trend (+9% vs last
  month). Add context (AOV rose, not sessions - a completely different story). Add a leading
  indicator (add-to-cart beside revenue). Four additions, and the tile now has a verdict.

## Watch for
- The 1:1 being run as a status report to the manager. Repeat that it is the report's meeting;
  status can be a document.
- Cadence set by seniority because that is how the calendar already looks.
- RAG status treated as a verdict rather than a conversation starter. Red starts talk.
- Dashboard maximalism - twelve tiles nobody reads. One metric that matters per horizon.

## Cuts if long
- The three horizons compress to naming each with its question and audience.
- Worked example 2 can stop after target and trend.
- Never cut the maturity-not-rank point or the naked-number fix. Those are the two changes people
  actually make on Monday.
